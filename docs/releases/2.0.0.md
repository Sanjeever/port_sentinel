# Port Sentinel 2.0.0

## English

- Rebuilt the desktop app with Go and Wails v2, React and HeroUI.
- Added macOS Universal and Ubuntu desktop packages alongside Windows amd64.
- Inspect TCP/UDP and IPv4/IPv6 connections, filter and sort ports, and open process details.
- Request graceful exit first, then explicitly confirm force termination when needed. Process identities are checked before operations; privileged actions use one-time system authorization.
- Added English and Simplified Chinese, system/light/dark themes, and saved user settings.
- Added official Release update checks and user-confirmed download, replacement and restart.
- Existing Flutter 1.x users must download and install 2.0.0 manually. User settings remain local. Unsigned packages may require operating-system approval.
- macOS packages without Developer ID credentials have an ad hoc signature and are not notarized. Windows packages are unsigned. Real UAC/polkit authorization, successful macOS administrator authentication and installed-app update/restart still require platform testing; automated checks do not certify these flows.

## 简体中文

- 使用 Go、Wails v2、React 和 HeroUI 重建桌面应用。
- 在 Windows amd64 之外增加 macOS Universal 和 Ubuntu 桌面分发包。
- 查看 TCP/UDP、IPv4/IPv6 连接，筛选和排序端口，打开进程详情。
- 默认请求正常退出，需要强制结束时另行确认。操作前复核进程身份；权限不足时按次请求系统授权。
- 增加简体中文和英文、跟随系统/浅色/深色主题及本地设置保存。
- 增加正式 Release 更新检查，由用户确认下载、替换与重启。
- Flutter 1.x 用户需要手动下载安装 2.0.0。设置保存在本机；未签名包可能需要操作系统批准。
- 未配置 Developer ID 凭据时，macOS 包使用临时签名且未经公证；Windows 包未签名。真实 UAC/polkit、macOS 管理员认证成功和已安装程序的升级重启仍需平台实测，自动化检查不代表这些流程已验收。

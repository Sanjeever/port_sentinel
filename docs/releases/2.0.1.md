# Port Sentinel 2.0.1

## English

- Reorganized the frontend into application, desktop bridge, ports, settings and shared component directories. Extracted the port toolbar, process results panel and update dialog while preserving existing behavior.
- Expanded English and Simplified Chinese regression coverage for toolbar actions, busy states, result dismissal, update confirmation and download cancellation.
- Ignore the Windows `info.json` template generated by Wails so local development keeps the Git working tree clean.
- Consolidated architecture and development documentation and updated code navigation.
- Windows packages are unsigned. macOS packages built without Developer ID credentials use an ad hoc signature and are not notarized.

## 简体中文

- 按应用、桌面桥接、端口、设置和通用组件整理前端目录，提取端口工具栏、进程操作结果面板和更新弹窗，保留现有行为。
- 补充英文与简体中文回归测试，覆盖工具栏操作、任务忙碌状态、结果面板关闭、更新确认与取消下载。
- 忽略 Wails 自动生成的 Windows `info.json` 模板，避免本地开发产生未跟踪文件提示。
- 整理架构与开发文档，更新代码导航。
- Windows 包未签名。未配置 Developer ID 凭据时，macOS 包使用临时签名且未经公证。

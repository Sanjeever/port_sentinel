# Port Sentinel 2.1.0

## English

- Redesigned the port workspace. Press ⌘F on macOS or Ctrl+F on Windows and Linux to search, with exact port and PID matches shown first. Narrow windows keep the local address and connection state visible.
- Open endpoint details alongside the table in wide windows or in a drawer in narrow windows. Inspect other connections owned by the same process and available process information, including the executable path, start time, working directory, and current parent process chain.
- Batch actions show selections outside the current filter and let you clear them separately. Termination results distinguish process outcomes from the rescan of the affected TCP listeners and UDP bindings, including endpoints that could not be confirmed.
- Updated the settings and update dialogs. Added shared development commands, frontend format and lint checks, Go race checks for service and update code, and a Chromium regression for narrow-window keyboard workflows.
- Windows packages are unsigned. macOS packages built without Developer ID credentials use an ad hoc signature and are not notarized.

## 简体中文

- 调整端口工作台。macOS 按 ⌘F，Windows 和 Linux 按 Ctrl+F 搜索，精确匹配的端口和 PID 优先显示。窄窗口保留本地地址和连接状态。
- 宽窗口可以对照表格和端点详情，窄窗口使用抽屉。详情展示同一进程的其他连接，以及可读取的可执行文件路径、启动时间、工作目录和当前父进程链。
- 批量操作会标明筛选外的勾选项，支持单独清除。结束操作分别展示进程结果和相关 TCP 监听、UDP 绑定的复查结果，并标明无法确认的端点。
- 更新设置和升级弹窗。统一开发命令，加入前端格式和 lint 检查、服务与更新模块的 Go 竞态检测，以及窄窗口键盘操作的 Chromium 回归测试。
- Windows 包未签名。未配置 Developer ID 凭据时，macOS 包使用临时签名且未经公证。
